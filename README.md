# Tic-Tac-Toe

A two-player tic-tac-toe game built with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS 4** and **shadcn/ui** components.

**Live:** https://tic-tac-toe-pi-ten-54.vercel.app

## Features

- Two players take turns as X and O on a 3×3 board
- Detects wins (rows, columns, diagonals) and draws
- One-click restart
- Responsive layout
- Vercel Web Analytics and Speed Insights (free tier, cookie-free)

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Deployment

Deployed on Vercel from the `main` branch. GitHub Actions builds every push and checks production dependencies for critical vulnerabilities.
